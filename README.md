## 🧪 Personal Project: Sales Dashboard (First Tableau Build)

🔗 My 1st Tableau Project : [Sales Dashboard](https://public.tableau.com/views/1stTableauproject_17461785872580/SalesDashboard?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

This was my first end-to-end Tableau dashboard project, inspired by real-world workflow and guided by best practices. The process followed:

### 📌 Project Workflow

1. **Analyze Requirements** – Define business questions and KPIs  
2. **Draw Mockups & Choose Colors** – Sketch dashboard layout and select a cohesive color palette  
3. **Build Data Source** – Clean and structure the dataset for dashboard-ready format  
4. **Create Charts**
5. **Assemble Dashboard**
