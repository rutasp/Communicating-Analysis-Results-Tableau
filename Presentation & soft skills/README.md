# Presentation and soft skills project: Executive presentation & sales overview
As part of my Data Analytics course at Turing College, I worked on a project for the fictional **AdventureWorks** company. I was tasked with creating an executive-level dashboard and delivering two presentations tailored to different audiences.

You can view the live dashboard here: [Tableau project - Executive & sales](https://public.tableau.com/app/profile/ruta.spaicyte/viz/AdventureWorksSalesdashboard_RS/SALES?publish=yes)

## Project Description

The goal of the project was to analyze AdventureWorks data and create one interactive dashboard that would support data-driven decision-making for both **executive leadership** and **department heads**. I chose to focus on the **Executive Leadership and Sales** combination.

## Approach

I developed a **sales performance dashboard** using Tableau Public, based on AdventureWorks sales order data. The dashboard was designed to provide high-level strategic insights for the executive team while allowing for more detailed, tactical use by sales department leads.

### Executive Presentation

I first presented the dashboard to an **executive audience** in a concise, high-level presentation (~5 minutes). The focus of this version was on:

- Key company-wide sales KPIs (e.g., total sales, average order value, YoY growth)
- Strategic insights like sales trends, regional performance, and online vs. offline sales distribution
- A brief overview of how the dashboard can support business goals and leadership decision-making

This presentation was designed to be **insightful yet time-efficient**, using clean visuals, minimal text, and clear value-oriented storytelling.

### Department Lead Presentation

I then delivered a more **detailed, tactical version (~10 minutes)** for sales department leads. In this version, I:

- Walked through specific filters and interactive features of the dashboard
- Highlighted how the team could use the tool for performance tracking and identifying areas for improvement
- Discussed how insights from the dashboard could help drive collaboration with other departments (e.g., marketing or operations)

## Reflections

Throughout this project, I focused on:

- Adapting communication to different levels of data literacy
- Designing visuals with a balance of clarity, detail, and visual appeal
- Anticipating stakeholder questions and preparing for discussion

I also documented possible limitations of the analysis, including the static nature of the dataset and the need for real-time integration in a production environment. Future improvements could involve incorporating customer segmentation or forecasting sales using machine learning.

This project helped me refine both my **data storytelling** and **dashboard design** skills in a business-relevant context.
